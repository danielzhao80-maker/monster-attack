# Monster Hunt: Abandoned City

A browser-based top-down shooter game built for Daniel.

## How to Play

1. Open `index.html` in a web browser (Chrome recommended)
2. Roll for a class (200 starting coins, 100 per roll)
3. Click **Fight!** to enter the abandoned city
4. Survive waves of monstrosities!

```bash
open -a "Google Chrome" index.html
```

## Tech Stack
- HTML5 Canvas
- Vanilla JavaScript
- Single file (`index.html`) — no dependencies

## Features
- 20 unique player classes across 5 rarities
- 13 monstrosity types across 5 rarities
- Gacha roll system for both players and monsters
- Unique abilities per class (freeze, teleport, revive, fire trail, etc.)
- Wave-based survival with scaling difficulty
- Pickups: health, ammo, coins
- Abandoned city map with buildings, shade zones, and destructible walls
