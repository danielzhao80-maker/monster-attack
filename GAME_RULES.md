# Monster Hunt: Abandoned City - Game Rules

## Overview
A top-down shooter set in an abandoned city. Roll for a class, fight waves of monstrosities, and survive as long as you can.

## Controls
| Key | Action |
|-----|--------|
| WASD / Arrow Keys | Move |
| Mouse | Aim |
| Left Click | Attack (shoot or melee) |
| R | Reload |
| E | Special ability |
| 1 / 2 / 3 | Speed Runner mode switch |

## Coins & Rolling
- Start with **200 coins**
- Each roll costs **100 coins** (2 rolls to start)
- You roll for a **player class** with a rarity system
- Earn **5 coins per kill** + coin pickups during gameplay
- At Game Over, you can roll again with 200 coins

## Rarity System (applies to both player classes and monsters)
| Rarity | Chance | Color |
|--------|--------|-------|
| Common | 40% | Gray |
| Rare | 30% | Blue |
| Epic | 18% | Purple |
| Legendary | 10% | Gold |
| Mythical | 2% | Red (glowing) |

## Wave System
- Wave 1 starts with 5 monsters
- Each wave adds 3 more monsters
- Monsters get **+20% HP** and **+8% speed** per wave
- Monster damage increases every 3 waves
- A new monstrosity class is rolled at the start of each wave

## Pickups (30% drop chance on kill)
| Pickup | Effect |
|--------|--------|
| Health (heart) | +25 HP |
| Ammo (gun) | +10 ammo |
| Coin | +20 coins |

## Map Features
- **Buildings** — block movement and bullets (except Ghost monsters)
- **Shade zones** — dark areas near buildings, safe for Vampire class
- **Walls** — built by Builder class, block monsters and bullets, have 3 HP
- **Fire trail** — left by Flame class, damages monsters walking through
- **Poison trail** — left by Toxic monsters, damages player walking through
